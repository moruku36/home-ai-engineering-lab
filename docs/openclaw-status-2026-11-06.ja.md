# ホームAIラボ：OpenClaw／クロッチ導入・検証記録

基準日：2026-11-06（JST）。対象：Mac mini 上の OpenClaw とラボ連携。

## 概要と証拠の範囲

OpenClaw（クロッチ）は、11月1日の設計だけの段階から、Mac mini への導入と限定的な動作確認まで進んだ。ブラウザの公開ページ読み取り、開発用 CLI のログイン、ラウンジの自動実行・受信をそれぞれ確認した。ただし、これらをラボ全体の運用受入れや三者の自律連携完了とは扱わない。

本書は当日までの作業会話で共有された実行結果・受信確認を公開用に整理した記録であり、この文書更新時に実機を再試験したものではない。生ログや認証画面は公開していないため、第三者がこのリポジトリだけで実行結果を再現・監査できる状態ではない。以下の「確認済み」はこの証拠範囲に限る。

既存の Ubuntu／NUC サービスや隔離解析ゲストは今回再確認していない。以前の正常・停止・未検証の記録を一括で更新したり、Mac mini の成功をそのまま他ホストへ適用したりしない。

## 導入で行った工夫

### 1. ホストと公開範囲を限定する

- Mac mini に OpenClaw 2026.10.10 を導入し、ローカルのループバックに限定した構成で確認した。
- ブラウザ実行は Docker の専用ネットワークへ分け、公開するポートもループバックに限定した。
- ブラウザ用コンテナに Docker socket をマウントしない構成にした。ホストの Docker 制御権限をブラウザへ渡す経路を作らないための工夫である。
- この構成確認は、ネットワーク全体の隔離・外向き通信遮断・コンテナ脱出耐性・エージェント間分離を証明するものではない。

### 2. ブラウザの動作確認と認証済みセッションを分ける

公開された Example Domain の見出しをブラウザツールの結果で確認し、「起動した」だけでなくページ内容を読み取れるところまで試した。実アカウントや私的なページを成功判定の材料にしない限定試験とした。

既存ブラウザの認証済みセッションを引き継ぐ経路は別扱いとする。その経路でエージェント間の状態や権限が隔離されることは未証明。Docker 側の公開ページ試験の成功を、認証済みセッションの安全な共有・分離の証拠に流用しない。

### 3. 開発用 CLI は段階ごとに判定する

Codex CLI と Claude Code CLI は導入・ログイン成功まで確認した。これはコマンドが利用可能になり、各 CLI の認証が成立したという段階の結果である。

OpenClaw のエージェントから目的の CLI を呼び出し、許可された入力で仕事を完了して結果を戻すところまでは未証明。CLI のログイン成功を、第三者ツール経由の認証利用許可や自動開発の受入れと読み替えない。認証方式・利用条件・権限境界は実際の連携方法に対して別途確認する。

### 4. ラウンジは実行終了と受信を別々に確認する

ラウンジのスケジューラーは 06:00〜22:00 JST、30分間隔の設定とした。最終の自動実行は終了コード 0 で完了し、受信も手動で確認した。プロセス終了だけを配送成功と見なさず、受信側の確認を分けた。

ただし、この結果は三者が自動で読み取り・返答し、再び受領する往復全体の成立を意味しない。稼働時間帯すべての周期、時間帯境界、再起動後の継続、重複・遅延・相手不在への対応も、この限定結果だけでは受入れ済みにしない。

## 次に完了させる検証

以下は残課題と合格条件の記録であり、今回実施した試験ではない。

1. **CLI のエージェント実利用**：機密を含まない限定タスクで、呼出し・終了・結果回収・失敗時の扱いを一連で記録する。認証成功だけで合格にしない。
2. **ブラウザの分離**：別エージェント／セッションが互いの認証状態やデータを参照できないことを、対象経路ごとに確認する。既存の認証引継ぎと Docker 経路を混同しない。
3. **三者自動往復**：自動投稿 → 相手の読取り → 返答 → 受領を同じ試験として追跡し、二重処理・相手不在・未送達を識別する。
4. **スケジュール継続**：稼働時間帯の境界と複数周期、再起動後を確認し、設定済みと継続稼働済みを区別する。
5. **ラボ運用の正式受入れ**：対象サービス、停止・保留状態、正常基準、報告先、保守時の担当移管を照合する。過去の Phase 5〜9 を一括で完了扱いにしない。

この更新は文書のみ。稼働構成の変更、認証の追加、権限の拡張、新しい通信、停止ジョブの再開、実機再試験は行っていない。導入済みという記録は、それらの操作許可や無制限の自律運用承認を意味しない。
