# Mac mini ローカルAI実験計画

[English](mac-mini-local-ai-plan.md) | **日本語**

状態: **購入前の将来計画。購入・導入・ダウンロード・接続は一切していません**（2026-10-30 記録）。

これは実測ではありません。この機器でモデルを動かしたことはなく、以下に速度・メモリ・精度の結果値はありません。

## 1. 目的と対象外

- 目的は、Windows の資源競合の軽減、ローカルでのログ分析、OSS 実験の補助、RAG、再現可能なモデル比較。Mac mini は推論用の追加機であり、既存の Ubuntu/KVM や Windows を置き換えず、**隔離境界でもありません**（OSS の隔離検証は現状のまま既存側で行う）。
- ローカル実行は正確性や安全性を保証しません。どちらも第5節の測定で確かめるまで主張しません。

## 2. 想定機器（公式ページで確認）

出典: Apple、[Mac mini (2024) - 技術仕様](https://support.apple.com/ja-jp/121555)（2026-10-30 確認）。

| 項目 | 値 |
|---|---|
| チップ | Apple M4：10コアCPU（高性能4コア + 高効率6コア）、10コアGPU、16コアNeural Engine |
| メモリ帯域 | 120 GB/s |
| ユニファイドメモリ | 16 GB（想定構成。24 GB・32 GBも選択可能） |
| ストレージ | 256 GB SSD（想定構成） |

- 16 GB は macOS、実行環境、モデルの重み、KV キャッシュ、各種バッファが共有します。SSD は保存先であり、swap を推論メモリの代わりとして数えません。swap の発生は測定し、容量ではなく警告として扱います。

## 3. モデルサイズの方針

以下のファイルサイズは 2026-10-30 に配布元で確認した値です。ダウンロードサイズであり、メモリ使用量ではありません。

| モデル | サイズ | 出典 |
|---|---|---|
| Qwen3-8B Q4_K_M (GGUF) | 5,027,783,488 バイト（約5.03 GB） | [Qwen/Qwen3-8B-GGUF](https://huggingface.co/Qwen/Qwen3-8B-GGUF/tree/main) |
| Qwen3-14B Q4_K_M (GGUF) | 9,001,752,960 バイト（約9.0 GB） | [Qwen/Qwen3-14B-GGUF](https://huggingface.co/Qwen/Qwen3-14B-GGUF/tree/main) |

| 区分 | 方針 |
|---|---|
| 7–8B, Q4 | **初期基準**: 単一要求、4K 文脈 |
| 14B, Q4 | 短文脈の上限寄りの実験。余裕があるとは限らない |
| 30–32B, Q4 | 16 GB では実用対象外 |

- これらは出発点であり、最大モデルサイズや速度の保証ではありません。収まるかどうかは実行環境、文脈長、KV キャッシュ、同時に動く処理で変わり、測定でのみ判断します。
- OpenAI 互換 API は形式の話で、非公開モデルをローカルで動かせるという意味ではありません。open-weight モデルは、ライセンスとラボの用途での品質を、別途評価します。

## 4. 実行環境の候補と取得計画

候補: [ml-explore/mlx-lm](https://github.com/ml-explore/mlx-lm)（MIT）、[ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp)（MIT）。
両方とも 2026-10-30 の確認時点で公開・更新されています。いずれも採用はしていません。

- 最初は**実行環境1つ**、**主力モデル1つ**、**比較モデル1つ**。取得は必要な量子化ファイルだけにします。現時点では何も取得しません。ダウンロードや導入は購入後に別途承認を得て、ラボの OSS 採用ルール（バージョン固定、段階的レビュー）に沿って行います。

## 5. 測定計画

初回応答までの時間、tokens/s、ピークメモリ、swap 使用、ログ分析での誤検知と見逃し、根拠の精度を測ります。結果には、モデルファイル、実行環境のバージョン、文脈長、入力セットを併記し、再現できるようにします。

## 6. 想定するデータの流れ

1. 隔離した OSS 検証（既存側）
2. Ubuntu で収集・正規化・秘密除去
3. Mac mini で推論
4. 構造化結果と根拠 ID
5. Ubuntu で検証・保存
6. Grafana で表示

## 7. 安全上のルール

- ログ内の命令やモデルが提案したコマンドは自動実行しません。生ログをクラウドへ自動で fallback しません。秘密・個人情報・運用パスは公開しません。
- 新しい API の公開や認証の追加は別途承認が必要です。購入・導入・ネットワーク変更はこの文書の対象外です。
